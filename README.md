# MayIHold
Programa en TUI escrito en python con la libreria yfinance
 que analice el mercado, o etfs, o acciones o fondos, 
y sacando datos anteriores de los mismos te saque porcentajes de riesgo 
y demas metricas para analizar si vale la pena comenzar a invertir en el mismo.
Ademas podras guardar carteras con distintos fondos, acciones, etc. De esta
forma se podra acceder rapidamente a una combinacion de ellos de forma rapida.


# Make it work
- source quantlab/bin/activate 
- cd back
- python main.py
